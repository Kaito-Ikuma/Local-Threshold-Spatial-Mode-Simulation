# Results

このディレクトリには、シミュレーションから生成された CSV、図、アニメーションを保存します。

- `spatial_mode_gaussian/`: Gaussian map の検証結果
- `spatial_mode_microscopic/`: microscopic dynamics の検証結果
- `presentation_materials/`: 比較図とパラメータスイープ結果
- `runs/`: ローカルでの一時実行用（Git 管理対象外）

各結果ディレクトリの `run_metadata.json` または `presentation_materials_metadata.json` に実行条件が保存されています。
